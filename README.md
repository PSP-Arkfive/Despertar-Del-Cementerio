# Despertar Del Cementerio
Latest version of the legendary unbricking tool for the Sony PSP.


## Installation

- Copy `DC10` to `/PSP/GAME/` on the Memory Stick. If you installed the Full variant of FasterARK then it should already be available on the PSP.
- Download the latest 6.61 firmware, rename it to `661.PBP` or `661GO.PBP` (for PSP Go) and copy to your Memory Stick.
- Latest `6.61` firmware for `non-Go` consoles: http://du01.psp.update.playstation.org/update/psp/image/us/2014_1212_6be8878f475ac5b1a499b95ab2f7d301/EBOOT.PBP
- Latest `6.61` firmware for `Go` consoles: http://du01.psp.update.playstation.org/update/psp/image2/us/2014_1212_fd0f7d0798b4f6e6d32ef95836740527/EBOOT.PBP
- Run the app and let it install.
- Use a recovery method such as `Pandora Battery`, `Baryon Sweeper` or `New cIPL` (booting the console with L trigger).


## Features

- Works on all retail PSP models (1K, 2K, 3K, Go and Street).
- Allows doing a fresh installation of `6.61` firmware with or without `ARK`.
- Can boot `6.61 ARK` from Memory Stick without doing any permanent changes to the device.
- Backup and restore nand.
- Backup and restore IDStorage
- Permanently change UMD drive region.
- and more...
